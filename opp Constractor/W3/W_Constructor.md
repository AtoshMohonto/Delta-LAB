#Constructors

1. A constructor is a special method that is automatically called when an object of a class is created.

2. To create a constructor, use the same name as the class, followed by parentheses ():

#Constructor Rules

1. The constructor has the same name as the class.
2. It has no return type (not even void).
3. It is usually declared public.
4. It is automatically called when an object is created
